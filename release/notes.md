## 更新内容

- macOS 后台服务新增绿色 C 菜单栏图标，悬停显示运行状态和版本；点击后可查看版本、检查更新、重启或退出服务。
- Windows 托盘菜单同样将“Codex转飞书”置于首项，点击弹出当前版本信息。
- 菜单更新继续使用下载校验、备份与失败回滚流程；重启或退出服务不会主动停止 Codex 桌面端正在执行的任务。
